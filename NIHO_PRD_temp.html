1. 项目概述

1.1 产品定位

NIHO智能销售赋能平台是一款面向B2B销售团队的企业级SaaS产品，由两个核心子系统构成：

子系统 定位 核心价值
企业内部智能知识库 销售团队的知识管理与智能检索中枢 让正确的知识在对的时间触达对的销售人员
销售语音分析与SOP优化 销售通话的AI分析与能力提升引擎 从通话数据中挖掘最佳实践，驱动销售方法论持续进化

1.2 目标用户

角色 核心诉求 对应页面
一线销售人员 快速获取产品知识、竞品信息；获得通话后诊断反馈；学习优秀话术 页面1/2/3/4/7
销售管理者 掌握团队能力全貌；识别标杆与短板；基于数据优化SOP 页面5/6
培训/运营人员 配置SOP流程；管理知识库标签与分类；维护案例库 页面2/6

1.3 核心设计原则

  • 权限隔离：知识库以"个人→部门→公司"三级权限体系为基础，确保信息安全
  • 数据驱动：SOP优化和案例生成均基于真实通话数据的统计分析
  • 闭环反馈：通话分析 → 能力诊断 → 学习推荐 → 效果验证，形成完整的销售能力提升闭环
  • AI原生：从知识搜索到话术生成，AI贯穿所有交互路径

2.1.3 数据逻辑

  • 知识空间权限映射：
  • 我的知识：visibility = "private" AND owner = current_user
  • 部门知识：visibility = "department" AND department = current_user.department
  • 公司知识：visibility = "company"
  • 排序规则：最近更新按 updated_at DESC；热门知识按 view_count DESC
  • 可见范围标签颜色：个人=灰色、部门=蓝色、全员=绿色

2.2.3 关键交互

  1. 音频-文本联动：点击转写文本中的时间戳 → 音频播放器currentTime跳转到对应秒数 → 时间戳高亮显示当前播放位置

  3. AI标签推荐：后台在文件上传后异步分析内容 → 提取关键词 → 生成推荐标签列表 → 用户进入详情页时展示在"+ 添加标签"下拉中

2.3.2 核心功能规格

功能点 详细说明
权限感知检索 所有回答仅基于当前用户有权限看到的知识（遵循"我的知识 > 部门知识 > 公司知识"三级权限），绝不跨权限提供信息
来源可追溯 每条关键信息后标注引用来源文档，格式为"《文档名》[章节/页码]"，点击可跳转到该文档详情页
场景化推荐 AI自动识别用户提问场景（如"竞品对比""价格异议""产品介绍"等），匹配对应SOP话术模板
多轮对话 支持上下文连续对话；用户可在同一会话中追问、细化问题
对话管理 支持清空当前对话、查看历史对话记录（列表展示，按时间倒序）
参考文件列表 在回答末尾列出所有引用的知识文件，用户可逐一查看原文

2.3.3 AI回答生成流程

用户提问 → 意图识别（分类：竞品对比/产品咨询/话术请求/SOP查询/其他）
       → 权限过滤（查询用户可访问的知识空间）
       → 语义检索（向量搜索 + 关键词搜索混合）
       → 结果排序（相关性 + 时效性 + 热度加权）
       → LLM生成回答（Prompt包含：用户问题、检索到的知识片段及来源、回答格式要求）
       → 引用校验（确保所有引用来源在用户权限范围内）
       → 渲染输出（Markdown格式 + 引用链接）

2.3.4 交互细节

  • 输入框：支持多行输入；Enter发送，Shift+Enter换行；placeholder文字："输入您的问题，例如'竞品A和我们的产品有什么区别？'"
  • 加载状态：AI思考时显示"正在为您检索知识库..."的加载动画
  • 错误处理：若未找到相关知识，回复"抱歉，当前知识库中暂无与此问题相关的信息。您可以尝试换个问法，或联系管理员补充相关资料。"
  • 反馈机制：每条AI回答下方提供👍👎按钮，用于收集回答质量反馈

3.2.3 高转化特征挖掘算法说明

  1. 分组：将所有历史通话按"是否在目标期限内达成成功目标"分为达成组和未达成组
  2. 特征提取：对每组通话提取N个行为特征（如"SOP步骤1完成率""客户提出异议次数""销售追问次数"等）
  3. 差异计算：计算每组各特征的均值，求差值
  4. 排序输出：按差异绝对值降序排列，标记差异显著（p<0.05）的特征
  5. AI总结：将Top特征输入LLM，生成自然语言描述和话术建议

4.1 角色路径说明

销售人员路径： 1. 每日上传通话录音 → 系统自动分析 2. 次日查看个人看板（能力雷达图、趋势、排名） 3. 根据诊断建议，学习优秀案例库中的对应话术 4. 在知识库中搜索产品/竞品信息，或使用智能问答助手

销售管理者路径： 1. 首次使用时，配置成功目标和SOP流程模板 2. 每日查看团队看板（团队指标、排名、高转化特征） 3. 根据特征挖掘结果，优化SOP话术 4. 关注低达成率销售，推送针对性学习内容 5. 查看优秀案例库，将标杆案例推广到团队

4.2 跨子系统数据流

语音分析系统                          知识库系统
──────────                          ──────────
通话录音 → AI分析 → 通话报告    →    自动归档到知识库（部门知识空间）
                → 优秀案例      →    进入金牌案例库
                → 话术建议      →    更新SOP模板
                → 特征挖掘      →    更新AI问答的话术库

知识库搜索 ← AI问答引用通话报告中的知识
知识库搜索 ← AI问答推荐案例库中的话术

5. 非功能性需求

5.1 性能要求

指标 要求
知识库搜索响应时间 P95 ≤ 500ms
AI问答响应时间 首字延迟 ≤ 2s，完整回答 ≤ 15s
录音上传速度 单文件上传 ≤ 10s（100MB以内）
录音分析完成时间 通话时长1:1处理（30分钟录音≤30分钟分析完成）
看板数据加载 P95 ≤ 2s
并发用户数 支持同一企业500+用户同时在线

5.2 安全要求

维度 要求
权限隔离 知识库三级权限必须严格隔离，禁止跨级访问
数据加密 通话录音文件存储加密（AES-256），传输加密（TLS 1.3）
操作审计 知识查看、下载、权限变更等操作记录审计日志
敏感信息脱敏 转写文本中的客户手机号、身份证号等信息自动脱敏
数据隔离 不同企业间数据物理/逻辑隔离

5.3 兼容性要求

维度 要求
浏览器 Chrome 90+、Edge 90+、Safari 15+
移动端 支持移动端H5适配（知识库查看、排名查看等核心功能）
音频格式 支持 MP3、WAV、M4A、AAC
文档格式 支持预览 PDF、DOCX、PPTX、XLSX
CRM对接 提供标准API接口，支持对接主流CRM系统（Salesforce、纷享销客、销售易等）

5.4 可用性要求

  • 系统可用性 ≥ 99.9%（除计划维护窗口外）
  • 核心功能（搜索、上传、看板）SLA ≥ 99.95%
  • 数据备份：每日全量备份，增量备份每小时一次
  • 灾难恢复：RPO ≤ 1小时，RTO ≤ 4小时

6. 附录：术语表

术语 定义
SOP Standard Operating Procedure，标准操作流程，指销售通话应遵循的标准化步骤
达成率 通话后达成成功目标的比例，公式：达成目标通话数 / 总通话数 × 100%
成功目标 管理者定义的通话成功判定标准，如"通话后7天内客户签单"
FAB Feature-Advantage-Benefit，产品介绍的"特性-优势-价值"方法论
知识空间 知识库的三级权限容器：我的知识（私人）、部门知识、公司知识
高转化特征 在达成目标的通话中显著更高频出现的行为特征
SPIN提问法 Situation-Problem-Implication-Need，一种销售需求挖掘方法
金牌特征 达成组与未达成组差异≥40%的行为特征
